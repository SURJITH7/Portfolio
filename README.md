# Surjith S J — Portfolio

A dark-themed, animated personal portfolio built with vanilla HTML, CSS, and JavaScript. Features scroll-triggered animations, a zigzag project showcase, and sections for my work experience, education, and certifications — designed to highlight my MERN stack development skills.
